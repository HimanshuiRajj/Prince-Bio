# PRINCE P13X - Bio Site

Single-page bio site with video background, music toggle and links to Telegram, Instagram, groups, bots and channels.

## Files
- `index.html` - page
- `style.css` - styles
- `bg.mp4` - background video + music (tap the speaker icon to unmute)
- `poster.jpg` - video poster frame

Host on GitHub Pages / Netlify / Vercel - no build step needed.
